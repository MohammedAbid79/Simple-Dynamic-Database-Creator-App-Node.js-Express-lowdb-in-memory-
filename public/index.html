Backups

Automatic Backups

P1 = newest snapshot (best-safe for crash recovery). Older snapshots are pruned automatically.

Backups are written to the backup/ folder on the server. A full snapshot captures all databases, records, users, API keys, webhooks and credentials. Individual per-database files let you restore a single table without affecting the rest.
